Avant de commencer

Ce qu'il faut savoir pour votre premier audit.

Faut-il savoir coder ou connecter GitHub ?

Pour lancer l'audit et lire les rapports, un compte gratuit et l'adresse de votre site suffisent. Les corrections dans le code nécessitent un dépôt GitHub compatible et une personne capable de relire les changements. Vous pouvez confier cette étape à votre développeur.

Mon site sera-t-il modifié pendant l'audit ?

L'audit consulte les pages accessibles. Dans le parcours de correction par pull request, les changements attendent votre validation ou celle de votre prestataire avant d'être intégrés au site.

Que comprend le plan gratuit ?

{% if gratuit %}{{ gratuit.sites }} site{% if gratuit.sites != 1 %}s{% endif %} suivi{% if gratuit.sites != 1 %}s{% endif %}, {{ gratuit.pages }} pages analysées par mois{% if gratuit.corrections %} et {{ gratuit.corrections }} corrections IA par mois sur un dépôt compatible{% endif %}. {% endif %}Les rapports PDF et CSV sont inclus. L'archive de données et de modèles à appliquer sans dépôt est disponible dès le plan Solo. Consultez le comparatif complet pour les autres limites.

Comment sont comptées les pages et les corrections ?

Chaque analyse consomme des pages du quota mensuel. Le nombre de pages possible est limité par vos réglages, le plafond par analyse et le quota mensuel restant : le plus petit s'applique. Une correction IA correspond à un fichier écrit par le modèle, même si ce fichier sert à plusieurs pages. Lire le détail des quotas.

Puis-je travailler avec mon prestataire ?

Vous pouvez lui transmettre les rapports PDF et CSV. Pour une correction dans le code, il peut relire les modifications proposées sur GitHub. Des comptes collaborateurs sont aussi disponibles selon le plan.

Quand verrai-je un effet sur mon référencement ?

L'audit montre les problèmes détectés et un nouveau passage permet de contrôler les changements. L'évolution des positions dépend ensuite de la réexploration par les moteurs, du contenu et de la concurrence. Le service ne garantit ni délai ni position dans Google.
