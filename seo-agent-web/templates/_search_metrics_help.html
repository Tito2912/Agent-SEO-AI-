Comprendre ces chiffres
Clics
Clics depuis un résultat de recherche vers votre site.
Impressions
Nombre d’affichages de votre site dans les résultats de recherche.
Taux de clics (CTR)
Part des affichages qui ont entraîné un clic. Par exemple, 2 clics pour 100 affichages donnent 2 %.
Position moyenne
Place moyenne observée dans les résultats. Plus le chiffre est petit, plus le résultat apparaît haut ; ce n’est pas un classement garanti.

Les totaux du graphique peuvent différer du tableau : le fournisseur ne détaille pas forcément toutes les recherches et la liste reçue peut être limitée.
