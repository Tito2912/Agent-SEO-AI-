Comprendre les chiffres
  • Chaque compte est compté une seule fois, même s’il possède plusieurs sites. Les actions d’un membre d’équipe bénéficient au propriétaire du projet.
  • Les comptes administrateurs et les inscriptions issues d’une invitation d’équipe sont exclus du parcours.
  • Une analyse doit contenir une page HTML visitée avec succès. Une tâche déclarée « corrigée » ou une modification enregistrée dans le CMS ne suffit pas à confirmer une correction.
  • Les premières étapes atteintes sont conservées si un site est supprimé, si une correction est rétablie ou si le site régresse ensuite. Ce suivi mesure le parcours passé, pas la santé actuelle du site.
