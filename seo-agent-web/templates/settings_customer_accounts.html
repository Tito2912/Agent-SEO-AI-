Comprendre les informations disponibles

La formule correspond aux droits actuels synchronisés dans Noyaru, comme dans les compteurs. Les essais restent distingués des abonnements actifs. Une résiliation programmée conserve les droits jusqu’à leur changement effectif.

La dernière connexion connue provient des connexions réussies par email ou Google présentes dans le journal. « Non renseignée » signifie qu’aucune date n’est disponible ; cela ne prouve pas une absence d’utilisation. Une session déjà ouverte n’ajoute pas de nouvelle connexion. Le filtre sur 30 jours utilise ces mêmes informations.

Les sites sont ceux que le compte possède actuellement. L’étape observée conserve la première progression suivie, même si un site a ensuite été supprimé. L’historique ancien n’est pas reconstruit. Les dates connues de chaque étape sont incluses dans le CSV ; une case vide indique une information absente.

La vérification d’email repose sur une preuve conservée de validation. « Vérification non retrouvée » ne signifie pas que l’adresse est invalide. Google associé indique un moyen d’accès enregistré, sans garantir une utilisation récente. Les analyses correspondent aux demandes enregistrées, tous états confondus ; une analyse terminée n’est pas nécessairement un rapport exploitable. Ouvrez la fiche pour consulter leur état et la consommation du mois.
